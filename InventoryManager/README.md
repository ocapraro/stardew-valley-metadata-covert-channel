# Encoder
The encoder

## Install Instructions
Set path
```sh
export STARDEW_VALLEY_PATH="/Users/ocapraro/Library/Application Support/Steam/steamapps/common/Stardew Valley/Contents/MacOS"
```

## Build Instructions
```sh
dotnet build
```

Ensure you have the .NET SDK installed. Navigate to the project directory and run the build command above. The compiled mod will be output to the `bin` directory.
